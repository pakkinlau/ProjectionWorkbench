# F2 ProjectLens Kernel v0

This module implements a bounded, deterministic subset of
`TaskRelativeRepresentationContract.v1`.

It preserves:

- project pointer versus snapshot versus derived lens;
- explicit `TaskContext` and domain-local `DomainChart`;
- deterministic lens identity;
- multidimensional information loss;
- typed lens mappings;
- noncompensatory gluing gates;
- lawful `NO_SAFE_GLOBALIZATION`, `NON_IDENTIFIABLE`, and
  `GRAMMAR_INSUFFICIENT` outcomes.

It does not establish a universal ontology, canonical representation, globally
optimal lens, scientific truth, human mastery, or external authority.
