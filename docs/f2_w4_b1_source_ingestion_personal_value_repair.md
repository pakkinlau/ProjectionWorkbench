# F2.W4.B1 — Source-semantic ingestion and personal-value repair

This branch adds a bounded, local-only source-ingestion membrane for Markdown,
JSON, and Git-like text. It derives a provisional project state and an exact
reentry candidate while preserving raw source custody.

The derived object is not canonical project truth. It records source digests,
ranked candidates, uncertainty, information loss, and no more than a small
confirmation budget.

The deterministic witness compares a generic task question with source-derived
status, blockers, and next action. It establishes mechanical repair only; human
retention and usability remain right-censored.
