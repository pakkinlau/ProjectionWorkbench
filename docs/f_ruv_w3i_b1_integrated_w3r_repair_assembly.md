# F.RUV.W3I.B1 — Integrated W3R Repair Assembly

This branch is a reproducible integration carrier. It reconstructs the W3R component repair line from immutable source heads and a content-addressed, gzip/base64 transport of the B1 patch inside GitHub Actions, runs the repository and component validation gates, and exports a combined patch and typed assembly report.

It does not merge sibling PRs, open Wave 4, establish human repeat-use value, or replace independent W3Q requalification.
